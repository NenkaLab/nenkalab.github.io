Jekyll이란?

Jekyll은 정적 사이트 생성기로, 간단하게 블로그를 만들 수 있게 해줍니다.

주요 특징

  • 간단한 설정: 복잡한 데이터베이스가 필요 없습니다
  • 마크다운 지원: .md 파일로 글을 작성할 수 있습니다
  • GitHub Pages 호환: 무료 호스팅이 가능합니다

코드 예시

console.log("Hello, Jekyll!");

def hello():
    print("안녕하세요!")
